# ほっぺ引っ張り移植メモ

`mobby-main` のカルーセル操作はゲーム内から外し、選択中のモビー1体へ操作を集中させています。キャラクター選択は「あつめる」タブの9枚のカードで行い、部屋・つくる画面では同じ選択中の1体を大きく表示します。

移植した挙動:

1. 4px以上動いた時だけ反応を開始。
2. 引っ張り方向を5セクターに分け、元実装の目ペアを選択。
3. 70px（またはステージ幅の16%）で強い目・口へ切り替え。
4. 本体を最大72px / 52pxだけ追従させ、横・縦の伸びと回転を加える。
5. 指を離すと本体はばねで戻り、表情は550msだけ残して通常へ戻る。

元サイトのメッシュ変形はWebのcanvas依存だったため、React Native / Expoでは、固定パーツ位置を埋めた穴なしの本体画像に透明目・口を重ねる構成に置き換えました。黒星キャラはさらに、カメラレンズ、十字操作キー、丸ボタンを独立した固定アクセサリーレイヤーへ分離しているため、ほっぺを引っぱっても本体だけが動きます。課金・ログイン・外部サービスはこの移植に含めていません。
