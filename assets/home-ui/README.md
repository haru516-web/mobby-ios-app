# Mobby ホーム UI アセット

`source/` にはユーザー提供の緑背景シートを原本のまま保存し、`scripts/process_home_ui_assets.py` で背景を除去した透過 PNG を生成しています。

- `logo/mobby-logo.png`: 上部 Mobby ロゴ
- `icons/`: ヘッダー、開閉ナビ、カルーセル矢印、5タブ用の個別アイコン
- `panels/`: クイックナビ、活動カード用のステッチ紙パネル
- `buttons/`: 活動カードのボタン素材
- `room-decor/`: 今後の部屋装飾に使える透過素材
- `sheets/`: 緑背景除去後の元シート（再切り出し用）

課金サービスや外部ストレージは使わず、すべてローカルアセットとして管理します。
