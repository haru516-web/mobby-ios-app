# キャラクター専用家具

各キャラクターの30種シートを5列×6行で分割した家具アセットです。

| キャラクター | 管理フォルダ | 使用条件 |
| --- | --- | --- |
| もびゆら | `mobiyura/` | もびゆら選択時のみ |
| れおもび | `reomoby/` | れおもび選択時のみ |
| ぽてもび | `potemoby/` | ぽてもび選択時のみ |
| もびち | `mobichi/` | もびち選択時のみ |
| 病みモビー | `yami/` | 病みモビー選択時のみ |
| もびりん | `mobirin/` | もびりん選択時のみ |
| もびやん | `mobiyan/` | もびやん選択時のみ |
| ばぶもび | `babumoby/` | ばぶもび選択時のみ |
| モビ坊 | `mobibou/` | モビ坊選択時のみ |

`src/data/characterFurnitureAssets.ts` が各ファイルを固有IDへ束ね、`Mobby2DScene` が現在のモビーと一致する家具だけを部屋へ描画します。つくるタブの家具パレットも選択中モビーの専用30種へ切り替わります。共通家具は別枠で引き続き利用できます。

元シートは `../character-sheets/` に保存し、分割処理は `scripts/split_character_furniture_sheets.py` で再生成できます。
